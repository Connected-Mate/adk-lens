Frequently asked questions

Does it change my agent code?

No. ADK Lens sits on top of ADK. Remove it with adk-lens off, then pip uninstall adk-lens.

Do I need an API key to try it?

No. adk-lens demo runs with a fake model, no key needed.

Where does my data go?

Nowhere: the board runs on your machine, at 127.0.0.1:4790. This site has no cookies and no trackers.

Is this a Google product?

No. It is an independent project under the MIT licence. “ADK” only names the tool it works with.
