Questions fréquentes

Est-ce que ça modifie mon code d'agent ?

Non. ADK Lens se pose par-dessus ADK. Tu l'enlèves avec adk-lens off, puis pip uninstall adk-lens.

Faut-il une clé d'API pour essayer ?

Non. adk-lens demo tourne avec un faux modèle, sans clé.

Où vont mes données ?

Nulle part : le tableau tourne sur ta machine, à l'adresse 127.0.0.1:4790. Ce site n'a ni cookie ni traceur.

C'est un produit Google ?

Non. C'est un projet indépendant, sous licence MIT. « ADK » désigne simplement l'outil avec lequel il fonctionne.
